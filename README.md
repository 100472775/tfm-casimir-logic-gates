## ¿Qué es este repositorio?
Este repositorio aloja el visor interactivo 3D en tiempo real desarrollado para el Trabajo de Fin de Máster. La herramienta permite visualizar dinámicamente el comportamiento mecánico y la respuesta de propagación óptica ($\lambda = 1550\text{ nm}$) en puertas lógicas optomecánicas reconfigurables sin contacto (**AND** y **OR**), cuya conmutación se basa en la modulación de las fuerzas de Casimir-Lifshitz mediante materiales de permitividad sintonizable por láser (GST en Metanol y ZnO en Cloroformo).
